# Analog Airwaves

A small NeoForge 1.21.1 radio-station extension for [Analog Audio](https://modrinth.com/mod/analog-audio), adding broadcast transmitters and portable frequency-tuned radios.

Place a transmitter directly on top of an Analog Audio radio, tune it to a frequency, then hold a portable radio tuned to the same frequency to listen.

Transmitters only broadcast while their chunk is loaded, and listeners must be in the same dimension. Multiple loaded stations on the same frequency cause interference.

Requires [Analog Audio 0.1.5-hotfix.1](https://modrinth.com/mod/analog-audio/version/BshMjyFt). [Source](https://github.com/palmmc/AnalogAudio)
